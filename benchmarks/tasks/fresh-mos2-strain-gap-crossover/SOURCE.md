# Source and transformations

This is a **fresh-start** task: every number the agent sees comes from new Quantum ESPRESSO 6.7 calculations (`pw.x`, `pp.x`) that the lab runs on request. No archived calculation results are served or used. The only external inputs are four pseudopotential files.

The physics question is paired, at the level of the scientific question only, with the Materials Cloud two-dimensional materials database: Campi, Mounet, Gibertini, Pizzi, Marzari, *The Materials Cloud 2D database (MC2D)*, ACS Nano (2023); Materials Cloud Archive record 17gf6-84915, DOI 10.24435/materialscloud:36-nd, CC BY 4.0 (relaxed monolayer structures and PBE band structures, including MoS2). No file of that record is used: the task grades protocol-specific values computed here with a different pseudopotential family and with spin–orbit coupling.

## Pseudopotentials

PSlibrary 1.0.0 (A. Dal Corso, *Pseudopotentials periodic table: From H to Pu*, Comput. Mater. Sci. 95, 337 (2014)), ultrasoft, PBE, generated by the author with `ld1.x` v6.3 (4 Sep 2018). The scalar-relativistic and fully relativistic files of each element come from the same generation input (rel = 1 and rel = 2), so spin–orbit effects are not confounded with a change of pseudopotential. Downloaded from the Quantum ESPRESSO pseudopotential library, https://pseudopotentials.quantum-espresso.org/upf_files/<file>.

## Calculations

- `environment/lab/task_lab.py` builds the three-atom 1H-MoS2 cell from the agent's structured request (kind, scalar or fully relativistic, lattice parameter, 2×2 in-plane strain tensor, S height and in-plane S shift, cell height, cutoff, scf mesh, band k points; ranges in `public.json`), writes the `pw.x` input, runs `mpirun -np 2 pw.x -npool 2` with one thread per rank (scf, or BFGS relaxation of the atomic positions at fixed cell), then `pp.x` (plot_num = 11, the bare + Hartree electrostatic potential) whose cube file is planar-averaged in numpy, then a `pw.x` band calculation at the requested k points. Fixed choices: PBE from the pseudopotentials, ecutrho = 8 ecutwfc, fixed occupations with 4 empty bands per spin channel, conv_thr 1e-10 Ry, local-TF mixing (β = 0.4), BFGS with forc_conv_thr 1e-4 Ry/bohr and etot_conv_thr 1e-6 Ry, masses Mo 95.95 and S 32.06 amu. Inputs and outputs of every job (`pw.in`, `pw.out`, `pp.in`, `pp.out`, `bands.in`, `bands.out`) are kept; wavefunctions, densities and cube files are deleted.
- The charge of a request is computed before it runs from its canonical size: the number of symmetry-distinct k points pw.x will use for the scf mesh (the lab reproduces pw.x's count from the symmetry of the strained, displaced cell; checked against pw.x on every construction run), ×3 for a relaxation, plus 0.25 per band k point, ×4 for spin–orbit and a cutoff factor.
- **Hidden references** were produced with the same `task_lab.run` code path, in the runtime image `ai-theorist-benchmark-runtime:20261007` on 2 cores (`benchmarks/construction/fresh-mos2-strain-gap-crossover/qe_batch.py`; requests in `reference_plan.py`; raw results in `reference_runs.jsonl`). `make_task.py` applies the estimators of `solution/solve.py` to them; the derived graded values are stored only in `environment/lab/private/`.

## What is hidden

The graded values (see `design.json` → `calibration`): the zero-stress lattice parameter; the two biaxial strains that bound the direct-gap range (spin–orbit band energies at scalar-relativistic relaxed-ion geometries) and the band edge that leaves K at each end with the point it moves to; the vacuum-referenced deformation potentials of the K valence and conduction states and of the direct gap; and, for −4 % uniaxial-stress compression along zigzag, the transverse strain, the band gap and the locations of the band edges. None is returned by the lab as such: each is a zero crossing, an interpolation, a finite difference or an extremum search over several calculations.

## Scope

New static-lattice PBE calculations (with spin–orbit coupling for the band energies; no quasiparticle, excitonic, zero-point or thermal effects) with one pseudopotential family and one code version: protocol-specific values, not experimental or literature numbers.
